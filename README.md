# LiveLens_screenTranslator

LiveLens — экранный переводчик на Qt/C++.

Программа делает скриншот экрана или выбранной области, распознаёт английский текст через Tesseract OCR и переводит его на русский язык. Поддерживаются обычный онлайн-перевод, технический режим с терминологической обработкой и пользовательские словари.

## Возможности

- захват всего экрана;
- захват выделенной области;
- захват текста рядом с курсором;
- распознавание текста через Tesseract OCR;
- онлайн-перевод через локальный сервер LibreTranslate;
- обычный режим перевода;
- технический режим перевода;
- отдельный пользовательский словарь для каждого режима;
- добавление слова в словарь через выделение области на экране;
- окно словаря с возможностью добавлять, удалять и очищать слова;
- автоматический перевод слова при добавлении в словарь;
- всплывающее окно с оригинальным текстом и переводом.

## Запуск готовой версии

1. Распаковать архив с программой.
2. Убедиться, что рядом с `scrtransl.exe` есть папка:

```text
tessdata/
└── eng.traineddata
```

3. Запустить локальный сервер LibreTranslate.
4. Запустить `scrtransl.exe`.

## Настройка LibreTranslate

Для работы онлайн-перевода приложение использует локальный сервер LibreTranslate.

LibreTranslate не входит в архив с программой и устанавливается отдельно. Перед запуском приложения сервер перевода должен быть запущен на адресе:

```text
http://127.0.0.1:5000
```

### Установка LibreTranslate

```bash
pip install libretranslate
```

### Установка модели английский -> русский

```bash
python -c "import argostranslate.package as p; p.update_package_index(); p.install_package_for_language_pair('en','ru'); print('Installed en->ru')"
```

### Запуск сервера

Обычный вариант:

```bash
libretranslate --load-only en,ru
```

Если команда `libretranslate` не находится, можно запустить через полный путь, например:

```bat
D:\Python\Python313\Scripts\libretranslate.exe --load-only en,ru
```

После запуска в консоли должно появиться:

```text
Running on http://127.0.0.1:5000
```

Окно с LibreTranslate закрывать нельзя, пока работает приложение.

## Tesseract

В Release-архив уже должна быть добавлена папка:

```text
tessdata/
└── eng.traineddata
```

Если программа сообщает, что папка `tessdata` не найдена, нужно положить папку `tessdata` рядом с `scrtransl.exe`.

## Возможные ошибки

### Ошибка перевода: Connection refused

Это значит, что LibreTranslate не запущен. Нужно запустить сервер:

```bash
libretranslate --load-only en,ru
```

и повторить перевод.

### Не найдена папка tessdata

Проверьте, что рядом с `scrtransl.exe` есть папка `tessdata` с файлом `eng.traineddata`.

## Пользовательские словари

В приложении есть два пользовательских словаря:

- обычный словарь;
- технический словарь.

Выбор словаря зависит от выбранного режима перевода.

В окне словаря можно:

- добавить английское слово;
- автоматически получить обычный перевод;
- вручную изменить перевод;
- удалить выбранное слово;
- очистить словарь.

Также можно добавить слово через выделение области на экране. В этом случае программа распознаёт выделенное слово и предлагает сохранить его перевод в словарь текущего режима.
